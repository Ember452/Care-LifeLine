# 药物相互作用安全要点

> 参考来源：国家药品监督管理局用药提示与 FDA 药品标签公开信息要点整理。

## 通用原则

- 就诊/配药时主动告知医生与药师正在使用的全部药品（处方药、非处方药、中药、保健品）。
- 多药联用未必禁止，但须由医生或药师权衡；禁止自行调整剂量或停药。
- 老年人、肝肾功能不全者、孕产妇的相互作用风险更高，属重点核对人群。

## 常见高危组合（提示性举例）

- 华法林 + 阿司匹林/布洛芬等 NSAIDs：出血风险显著增加；华法林使用者应避免自行服用止痛药，并定期监测 INR。
- 华法林 + 胺碘酮/甲硝唑：抑制华法林代谢，抗凝作用增强，INR 升高；合用须监测并调整剂量。
- 利福平 + 华法林：诱导肝酶代谢，抗凝疗效减弱，可能需要上调剂量（由医生评估）。
- 他汀类 + 克拉霉素/伊曲康唑：CYP3A4 抑制使他汀暴露升高，横纹肌溶解风险增加；出现肌痛、乏力、酱油色尿应立即就医。
- 氯吡格雷 + 奥美拉唑：CYP2C19 抑制降低氯吡格雷活化，抗血小板疗效下降；如需抑酸治疗可与医生讨论换用其他质子泵抑制剂。
- ACEI/ARB + 螺内酯/钾补充剂：高钾血症风险，须定期复查血钾。
- 二甲双胍 + 碘造影剂：造影检查前后按医嘱暂停，警惕乳酸酸中毒；与大量饮酒同用亦增加风险。
- 碳酸锂 + 噻嗪类利尿剂：血锂浓度升高，易致锂中毒（手抖、口齿不清、嗜睡须就医）。
- 对乙酰氨基酚 + 长期饮酒：肝毒性风险增加，慢性饮酒者应控制剂量并告知医生。
- 甲氨蝶呤 + NSAIDs：减少甲氨蝶呤清除，骨髓抑制与肾毒性风险增加。

## 就医提示

- 用药后出现皮疹、黄疸、酱油色尿、肌痛、异常出血、意识改变等新发症状，及时就医并携带完整用药清单。
- 以上内容为用药安全科普，不替代执业医师与药师的个体化指导。
