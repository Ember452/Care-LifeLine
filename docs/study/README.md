# 学习笔记（docs/study/）

本项目是**大厂 Agent 岗位面试作品**。本目录沉淀实现过程中"值得面试官听"的东西——把每一段工程实践变成能讲 30 秒到 3 分钟的面试故事。

## 与 ADR 的分工

| | ADR（`docs/decisions/`） | 学习笔记（`docs/study/`） |
|---|---|---|
| 目的 | 记录决策，防止协作者推翻 | 沉淀叙事，防止面试忘记怎么讲 |
| 对象 | 协作者 / AI Agent | 面试准备者（自己） |
| 内容 | 状态/背景/决策/备选/后果 | 背景问题/实现要点/面试预演 |
| 何时写 | 做出重大决策时 | 完成有讲述价值的功能/修复/优化时 |

## 何时写

完成一个功能、修复或优化后，自问：**"这个实现面试官会感兴趣吗？"**

值得写的信号：

- 有架构取舍（如：为什么多 Agent 而不是单 Agent、流式与质控冲突怎么解）
- 有可量化的改进（延迟 / 成本 / 幻觉率 / 覆盖率的变化）
- 有踩坑教训（中文 SSE 截断、报告解析回退策略等）
- 有工程技巧（模型分级路由、阈值校准、防评测泄漏）
- 有"从 X 到 Y"的成长故事

不值得写的：常规 CRUD、纯脚手架、无权衡的直译实现。

