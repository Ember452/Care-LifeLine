# 0002 质控双层把关设计

## 背景

医疗场景的安全不能只靠 prompt 约束：不可测试、不可度量、不可追溯。需要把"医疗安全"变成可测试的工程能力。

## 决策

质控 Agent 采用**双层把关**：

1. **规则层（确定性，必过）**：纯函数实现，输入（draft + patient_context）→ `list[Violation]`。覆盖越界拦截、紧急词识别、输出格式校验。可单测（覆盖率 100% 门禁）、规则集版本化（`qc_rules` 表）、命中全部进审计。
2. **LLM 语义评审层**：faithfulness（证据支撑度）+ 风险评分 0–1；**阈值经校准流程确定**（历史标注集上取误放行率 ≤5% 的选点），不拍脑袋。

## 备选方案

- 仅 prompt 约束：不可测、不可控，不选。
- 仅 LLM 评审：不可靠（LLM 波动）、不可单测、成本高，不选。

## 后果

- 正面：规则层保证底线（可单测、可版本化），LLM 层处理语义；"安全 = 可测试工程"是核心差异化叙事。
- 负面：双层带来额外延迟与 token 成本（模型分级路由缓解）；阈值需随数据持续校准。
