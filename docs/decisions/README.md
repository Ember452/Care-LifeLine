# 重大决策记录（ADR）

本目录记录 Care-LifeLine 的重大架构与技术决策（Architecture Decision Record），是设计演进的可追溯依据。

## 规则

- **何时写**：任何影响架构 / 接口 / 数据模型 / 关键流程的决策，在做出决定时立即补写，不拖延、不口头留存。
- **命名**：`NNNN-短横线主题.md`，编号递增不重用。
- **状态**：`已接受` / `提议` / `已废弃`；被推翻的决策改为"已废弃"并在正文注明原因，不删除文件。
- 关联改动前先读本目录，避免推翻已确认的取舍。

## 模板

```markdown
---
状态: 已接受 | 提议 | 已废弃
日期: YYYY-MM-DD
关联: （相关 ADR / Issue，可选）
---

# 标题

## 背景

为什么需要做这个决策。

## 决策

我们决定……

## 备选方案

考虑过但没有选择的方案，及不选的原因。

## 后果

正面与负面影响的取舍。
```
