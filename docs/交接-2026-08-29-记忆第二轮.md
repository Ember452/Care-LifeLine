（规则+LLM 双层）+ 数据闭环。Python 3.13 + uv + FastAPI + React18/Arco。

## 已知坑（踩过的，别再踩）

1. **ruff 行宽 100 严格**：中文字符串拼接时优先拆行；`python - <<EOF`
   heredoc 里写替换字符串时注意引号转义。
2. **mypy 条件定义**：async/sync 工厂函数必须拆开写（条件内嵌套 def
   会报 "conditional function variants" 错）。
3. **LangGraph**：编译子图经 `.invoke` 接入（不可直接调用）；async 节点
   用 `functools.partial` 传依赖（lambda 丢协程语义）；updates 流对子图
   输出聚合增量。
4. **Arco 前端**：`http.del` 不是 `http.delete`；`PatientItem` 等类型
   定义在 `types/contract.ts`；测试环境 `get_settings` 用
   `monkeypatch.setenv + get_settings.cache_clear()` 组合。
5. **SQLite dev 库 schema 演进**：`init_db` 是 create_all，加列不会
   迁移旧库——schema 变更后删 `care.db*` 重建即可（种子数据）。
6. **RxNav interaction API 已下线**（2024-01），别按旧教程接；openFDA
   的 404 是"无记录"不是错误（ADR-0012）。
7. **提取器正则**：贪婪捕获 + 语气词/主语剥离 + 连词拆分，都来自真机
   回归——改动后务必跑 `test_memory_extractor.py` 全部用例。
8. **Git Bash 下 curl 发中文 JSON 会按 GBK 编码**：服务端 UTF-8 解码
   后正文成乱码（正则/关键词全部失效且不报错）。中文请求体必须先写
   UTF-8 文件再 `curl --data-binary @file`。此前会话列表里的乱码
   标题即此原因。
9. **应用 logger.info 默认不可见**：uvicorn 只为 uvicorn.* 配置了
   handler，应用 logger 无 handler 时走 lastResort（仅 WARNING+）。
   临时探针要用 warning 及以上级别。
10. **create_proposal 的同内容 pending 去重是设计行为**：冒烟测试用
    重复药名会"静默无提议"，换新药名即可；这不是 bug。
